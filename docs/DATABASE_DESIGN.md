# Database Design – Smart Farming AI

## 1. Introduction

Smart Farming AI will use MySQL to store and manage application data. The database will maintain user information, soil details, crop recommendations, and previous farming records.

## 2. Database Name

`smart_farming_ai`

## 3. Main Database Tables

### 1. Users
Stores user registration and login details.

- user_id (Primary Key)
- name
- email
- password
- created_at

### 2. Soil Details
Stores soil information entered by users.

- soil_id (Primary Key)
- user_id (Foreign Key)
- nitrogen
- phosphorus
- potassium
- ph_value

### 3. Crop Recommendations
Stores crop suggestions generated by the application.

- recommendation_id (Primary Key)
- user_id (Foreign Key)
- recommended_crop
- created_at

### 4. Fertilizer Recommendations
Stores fertilizer suggestions.

- fertilizer_id (Primary Key)
- user_id (Foreign Key)
- fertilizer_name
- created_at

### 5. Weather Records
Stores weather information.

- weather_id (Primary Key)
- user_id (Foreign Key)
- temperature
- humidity
- rainfall
- recorded_at

### 6. Disease Detection History
Stores plant disease detection results.

- detection_id (Primary Key)
- user_id (Foreign Key)
- image_path
- detected_disease
- created_at

## 4. Database Relationships

- One user can have multiple soil records.
- One user can receive multiple crop recommendations.
- One user can have multiple fertilizer recommendations.
- One user can have multiple weather records.
- One user can have multiple disease detection records.

## 5. Conclusion

The MySQL database will help organize application data and make it easier to store, update, and retrieve farming information.
