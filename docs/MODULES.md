# Modules – Smart Farming AI

The Smart Farming AI application is divided into different modules. Each module performs a specific task to make farming easier.

## 1. User Management Module

- Allows users to register and log in.
- Manages user profiles.
- Provides secure access to the application.

## 2. Dashboard Module

- Displays important farming information.
- Provides access to different features.
- Shows previous recommendations.

## 3. Crop Recommendation Module

- Takes soil details as input.
- Suggests suitable crops based on the available information.

## 4. Soil Analysis Module

- Collects soil information.
- Checks values such as pH, nitrogen, phosphorus, and potassium.
- Displays soil-related results.

## 5. Fertilizer Recommendation Module

- Uses soil nutrient information.
- Suggests suitable fertilizers for better crop management.

## 6. Weather Module

- Displays current weather information.
- Helps farmers check temperature, humidity, and rainfall details.

## 7. Plant Disease Detection Module

- Allows users to upload plant leaf images.
- Helps identify possible plant diseases using image analysis.

## 8. History Module

- Stores previous recommendations.
- Allows users to view their past farming activities.
