# Technology Stack – Smart Farming AI

The following technologies will be used to develop the Smart Farming AI application.

## 1. Java

Java will be used as the main programming language for developing the application.

## 2. Spring Boot

Spring Boot will be used to develop the backend and handle application requests.

## 3. MySQL

MySQL will be used to store user details, soil information, crop recommendations, and other records.

## 4. HTML

HTML will be used to create the structure of web pages.

## 5. CSS

CSS will be used to design and style the application.

## 6. JavaScript

JavaScript will be used to make the website interactive.

## 7. Bootstrap

Bootstrap will help create a responsive design that works on different screen sizes.

## 8. Spring Data JPA and Hibernate

These technologies will help Java communicate with the MySQL database.

## 9. Maven

Maven will be used to manage project dependencies and build the application.

## 10. Git and GitHub

Git and GitHub will be used to manage code and maintain project versions.
