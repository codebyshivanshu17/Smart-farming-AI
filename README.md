# 🌱 Smart Farming AI

### Smart Agriculture Management System Using Java

Smart Farming AI is a web-based application designed to help farmers make better farming decisions using modern technology and Artificial Intelligence. It aims to provide crop recommendations, soil analysis, fertilizer suggestions, weather updates, and plant disease detection in one platform.

## 🎯 Objectives

- Help farmers select suitable crops.
- Provide soil-related information.
- Suggest suitable fertilizers.
- Display weather updates.
- Support plant disease detection.
- Make farming information easily accessible.

## 🚀 Main Features

- User Registration and Login
- Crop Recommendation
- Soil Analysis
- Fertilizer Recommendation
- Weather Monitoring
- Plant Disease Detection
- Farming Dashboard
- Previous Activity History
